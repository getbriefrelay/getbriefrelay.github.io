# BriefRelay Team Avatars

Created by Vega for Telegram, Instagram, reports, and future website use.

Design direction: a unified vector avatar family based on the active BriefRelay V4D mark: rounded square field, tactile paper center, desk-green strokes, bold coral/teal/yellow accents, and role-specific work symbols.
